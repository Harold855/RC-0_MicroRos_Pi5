# plots/

Dos PNG por bag, generados con `python3 capytown_esan/plot_odom.py bags/<bag>`:

- `<bag>_xy.png`: trayectoria x–y relativa a la pose inicial (se ve el desvío lateral).
- `<bag>_theta_t.png`: orientación θ(t) acumulada, en grados.

Con los cuatro bags finales deben quedar al menos ocho PNG. Los de prueba con datos sintéticos
(`SINTETICO_*`) no se entregan.
